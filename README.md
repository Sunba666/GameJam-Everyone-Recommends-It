# 《大家都推荐》

21 天 Unity2D GameJam 项目。玩家推荐猫、美食、游戏、新闻或音乐，观察居民的反应，探索个人选择如何成为公共潮流。

## 运行

- 使用团结引擎 **1.10.4 / 2022.3.62t16**，项目采用 URP 2D、UGUI 和旧输入系统。
- 在 Hub 中添加仓库根目录，打开 `Assets/Scenes/MainMenu.scene`，点击 Play。
- 点击“开始推荐”进入独立的 `Residents.scene`；居民楼内可以返回首页。

## 当前进度

已完成主界面人物动画、场景转场、全局光标、音乐、设置、玩法说明、成就入口和退出按钮。居民楼预览支持楼层切换与主题反馈。

十二阶段、概率传播、昼夜变化、回放和成就解锁尚待实现。Windows 预览已验证；WebGL 构建需要安装对应模块。

## 目录

- `Assets/`：脚本、场景、预制体及美术音频，保留全部 `.meta` 引用。
- `Packages/`、`ProjectSettings/`：依赖与项目配置。
- `Design/`：玩法方案、工具及[主界面使用说明](Design/主界面与双场景使用说明.md)。
- `ArtConcepts/`：概念图与设计参考。

缓存、本机设置、构建包与历史备份由 `.gitignore` 排除。
