# 主界面与双场景

## 直接运行

打开 `Assets/Scenes/MainMenu.scene`，点击编辑器 Play。开始推荐会经人物纸色遮罩转场进入独立的 `Assets/Scenes/Residents.scene`。居民楼右下角可以返回首页。

两个场景均可独立打开运行，均有自己的摄像机与 EventSystem。全局服务会自动去重，在切换时保存光标、音量及动态效果设置。原有 SampleScene 保留。

## 已接入的交互

- 主界面五组人物依次缩放渐显，带圆形柔边底色；随后循环小幅摆动。
- 怎么玩：三页说明、上下页、返回和关闭。
- 设置：总音量、音乐、音效、百分比、全屏、动态效果、恢复默认、返回和关闭；设置立即生效并本机保存。全屏在独立程序中生效，编辑器仅保存勾选状态。
- 成就：打开、返回和关闭。现有六格保持素材中的未解锁展示；尚未定义成就条件，因此没有虚构解锁数据。
- 退出游戏：与怎么玩、设置、成就组成居中的四按钮行，含悬停、按下和点击音效。Windows 版直接关闭程序；编辑器停止 Play；WebGL 显示可关闭的提示，说明关闭浏览器标签页即可退出。
- 开始推荐与返回首页：两侧等量人物带着纸色长条相向移动，遮住画面后加载场景，再继续移出；退场 1.5 秒、进场 1.2 秒。期间屏蔽重复点击。关闭动态效果后改为淡入淡出。
- 自定义光标跨场景保留。退出运行时恢复默认光标。
- 居民楼是菜单的可交互承接预览：楼层选择、五类内容按钮、住户动作及状态图标变化、设置与返回。还没有接入十二阶段、概率传播、昼夜及回放系统。

## 可调整的位置

- 主界面根对象的 `MenuEntrance`：入场时间、组间延迟、横向摆幅和角度。
- `Assets/Prefabs/UI/FrontendServices.prefab` 的 `CharacterSceneWipe`：两段转场时长、纸色和人物素材。
- 同一预制体的 `FrontendServices`：光标图片与热点、背景音乐和点击音效。新版 `MenuCourtyardLoop.wav` 为原创合成纯音乐：84 BPM、16 小节、45.714 秒、44.1 kHz 立体声，柔和键盘旋律、和弦、低音与循环混响；启动时 0.75 秒渐入。旧版音频保留。
- 设置与成就根对象的 `PopupSlide`：弹窗从上方滑入，默认 0.52 秒，五次缓出曲线，无回弹。遮暗层覆盖全屏；关闭动态效果时直接显示。反复打开不会累积位移。
- `ResidentsCanvas` 的 `ResidentsView`：承接场景按钮、住户、主题图标。未来在 `SelectTopic` 处接入真实推荐模拟。

## 编辑与重新生成

所有场景对象和参数都可在 Inspector 编辑，无需重新生成。`Everyone Recommends > Build Start Menu And Residents Scenes` 是首次搭建/重建工具；再次使用会重建这两个场景，旧文件先备份到 `Design/MenuImplementationBackup_20261004`，手动布局调整应在重新生成前另存。

素材原始预制体保留在 `Assets/EveryoneRecommends`；搭建时展开到新场景，不覆盖外部素材包。字体来自本机黑体，正式对外发布前请替换为项目已获分发许可的字体。

2026-10-05 的优化直接修补现有场景，保留此前手工布局；备份位于 `Design/MenuPolishBackup_20261005_003855`。`Polish Existing Frontend` 可重新应用平滑导入、弹窗组件与新音乐。135 张图片使用 Bilinear、无压缩和保留源图分辨率；没有人为锐化或重绘原图。

`Everyone Recommends > Add Exit Button To Existing Menu` 只补齐退出按钮并调整这一行，不重建场景。第一次添加前的完整场景保存在 `Design/MenuExitBackup_20261005_095028`；重复执行保留现有按钮布局。退出行为位于 `MenuView.ExitGame`。

Game 视图的分辨率下拉菜单中，已关闭 `Low Resolution Aspect Ratios`，避免高 DPI 屏幕把低分辨率预览放大产生额外锯齿。预览保持 1x 或适合窗口；不要把低分辨率输出放大作为最终画质判断。

转场拖尾改为超过整条屏幕对角线，并增加横向越界和相邻条带重叠。完全覆盖时另有满屏纸色保护层，异步加载期间保持遮住；新场景就绪后再继续运动退场。
