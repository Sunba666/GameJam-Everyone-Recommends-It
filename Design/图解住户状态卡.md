# 图解住户状态卡

2026-10-10，按新的底板与设计示例接入。此版将原本隐藏的接触压力和个人临界点改为可见图形；真实兴趣数值及接收概率仍隐藏。采用已有 PNG 原件，不重绘或覆盖原图。

## 玩家怎么看

- 左上是该住户当前动作头像及房号，右上是当前偏好。头像跟随场景动画，偏好不会因为刚收到不同主题就直接替换。
- 猫、美食、游戏、新闻、音乐分别有十格饱和度。颜色越满代表最近接触压力越大；部分格填充表示实际的中间值。
- 每行黑色竖线来自这位住户对该主题的独立阈值。不同住户、不同主题可能不同，同一局跨阶段保留。
- 笑脸表示有兴趣且没看腻，平脸表示兴趣一般，皱眉及叹号表示压力达到临界点。仍然喜欢一个主题，也可能对连续推送感到厌烦。
- 卡片下方保留最近接收内容、来源、真实反应和最近两次接收轨迹。观察时暂停，关闭恢复。
- 右侧主题按钮保持可用，选主题不发送；只有“确认推荐”消耗机会。“暂不推荐”、右上关闭或 Esc 不消耗未提交机会。

## 布局和修改入口

观察卡固定在右侧简图区域，上方目标和下方主题按钮保持可见，准备发送的主题显示在确认按钮上，避免挡住楼内住户。观察时暂时隐藏简图节点、楼层按钮、重复选择提示和主题区标题，关卡片后恢复；上下层与全楼视图按钮保留。

- `Assets/Scripts/UI/Residents/ResidentStatusCard.cs`：读取实际状态、条格/表情更新、暂停说明及侧栏显示恢复。所有显示逻辑只读正式数据。
- `Assets/Editor/SceneSetup/IllustratedStatusCardInstaller.cs`：按原图 1120×1400 坐标对齐图层。卡片美术 340×425，整个交互区域 356×548，中心为画板坐标 (620, 40)。布局采用固定坐标，避免缩小字体。
- `Assets/Scripts/UI/Graphics/AttitudeFaceGraphic.cs`：原生 UGUI 表情，位于底板原有圆圈内。
- `Everyone Recommends > Install Illustrated Resident Card`：只修改 Residents 场景并先备份。综合 UI 整理工具也会保留此新版卡片。
- `Library/frontend-command.txt` 可写入 `refresh`、`statuscard`、Play 后 `statuscardqa`。先完成脚本编译再运行新命令；不要使用重建整场景的 `build` 命令。
