# 完整居民楼背景与夜间灯光

工具：内置 imagegen，编辑模式；以原 `住宅全景与固定UI.png` 为参考。保留原图，新图保存为 `Assets/Art/Building/Building_CompleteDay_v2.png`（1671×941），在 Unity 的原 1672×941 坐标空间中整张显示。

本次生成提示：制作一张连续完整的白天居民楼背景；保持原有摄像机、楼体轮廓、三层高度、栏杆、门窗、沙发桌椅、灯具、楼梯、树木和街道的位置与手绘水彩风格。只去掉左上固化标题、左下固化按钮及右侧全部固化界面图案，重建其后的天空、地面和空白纸底。保留建筑上的 3F/2F/1F 标牌。禁止加住户、切条、拼板、改变视角、重排房间或移动灯具。

场景背景只使用新图的一个完整 Sprite，旧 `FixedBuildingHeader` 与 `FixedBuildingFooter` 场景对象已移除。标题使用独立透明 UI 图，不再参与背景拼接。

夜间效果由 `ApartmentLighting.shader` 和 `ApartmentBackdrop` 控制：室外冷色暗光、室内环境光，以及按图中 12 处吊灯、台灯、落地灯定位的暖色照明锥和灯泡光晕。照明跟随背景 UV 和楼层镜头移动；亮度变化不分割背景，住户使用轻微暖色调整以保持清晰。

这是一套适合 UGUI 插画场景的二维光照表现，不是三维阴影或物理光照模拟。`ApartmentBackdrop / Lamp Strength` 可调整灯光强度。昼夜及回放时间来自现有游戏时间，不改变推荐或随机结果。
