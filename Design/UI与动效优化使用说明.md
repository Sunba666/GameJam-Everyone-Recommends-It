# UI 与动效优化

2026-10-08。在现有两场景、美术及住户布局上修补。

2026-10-10：下面记录中的旧文字观察卡已由[图解状态卡](图解住户状态卡.md)替代，新卡布局由 IllustratedStatusCardInstaller 控制，不再由旧 Card Size 参数决定；其他按钮、气泡及镜头参数保持有效。

## 玩家能看到的改变

- 标题、游戏、弹窗及成就按钮的文字/图标有轻微悬停和按压反馈。按钮点击区域保持固定，避免放大时把鼠标挤出点击区；关闭动态效果时立即回到静态。
- 观察卡扩大为 300×400，正文固定为 17 号字，接收轨迹独立显示，不再把长文本缩到 14 号。卡片显示“观察中 · 时间暂停”，并避开三个住户。
- 主题区域明确显示当前房号与准备推荐的内容；已推荐及教学后等待开始阶段都有对应说明。再次点击当前楼层不会丢掉未提交选择。
- 住户反应使用小纸底板，避免直接压在家具纹理上。进入和消退轻柔，保留真实反应文字；手动暂停或设置时不会悄悄过期。
- 计时条说明当前为什么暂停。最后 15 秒只增加文字颜色提醒，不闪屏。选中楼层有纸色标记。
- 动态效果关闭时，正在进行的楼层切换会完成到稳定画面，不停在半透明或半放大状态。剧情、设置和场景转场原有操作保留。

## 开发者调整入口

统一配置在 `Assets/Resources/UIFeedback/Default.asset`。Inspector 调整：按钮悬停/按压倍率与响应时间、反应显示与淡入淡出时间、楼层淡出淡入时间、镜头收稳倍率与响应、观察卡大小/字号/定位搜索步长及选中色。

按钮与气泡动效读取配置；观察卡几何/字号修改后，停止 Play，再运行 `Everyone Recommends > Polish UI And Motion` 更新两场景。工具只补齐或调整既有对象，重复运行不应叠加气泡/脚本；保存修改前先备份，保留原住户坐标和 .meta。

新增普通按钮时挂 `UiButtonFeedback`，指定现有文字/图标子对象作为 Visuals。保持 Button 的 RectTransform 不动，不把住户动画根节点交给它。

反应纸底使用已有空白卡片素材和 UGUI CanvasGroup。新增原生 Unity 组件用 Unity 对象的空值判断后显式添加，避免把原生组件的“假空引用”当成有效组件；运行时也补齐必需的 CanvasGroup。无需引入补间库或自定义 UI 框架。

## 减少重复工作

- 观察卡只在目标位置、视口、尺寸或保留区域变化时重新搜索。场景静止时沿用结果，复用角点数组，避免每帧进行完整网格搜索。
- HUD 根据操作状态刷新；计时文字按整数秒更新，来源说明按送达事件更新。计时进度仍使用当前正式时间。
- 音量滑块立即更新实际音量，松开后或关闭设置时统一保存。连续拖动不再每次变化都写本地存档；退出程序仍保存设置。
- 新 UI 不写兴趣、压力、推荐次数、随机种子或成就结果。只读回放清理实时送达气泡。

## 验证与边界

专项运行检查、原生截图及包信息在 `Builds/Verification/UIPolish`。验证点击范围、动效关闭、观察卡边界/遮挡、选择不发送、确认一次、暂停提示、气泡生命周期、缓存命中、音量即时响应与合并保存、回放及成就入口。

减少布局搜索和保存次数属于运行证据，不等同于所有机器上的 FPS 已提升。不同窗口尺寸的字体舒适度、气泡停留时间与整体耐玩性仍以真人反馈调整。

专项检查当前为 24 项，包含 120 次静止定位请求不重复搜索、50 次音量变化即时生效且关闭时只保存一次。标题中原本把文字画在整张按钮 PNG 的控件，改为透明的固定点击图层与独立 ButtonArtwork 显示子对象；Sprite Swap 仍指向真实显示图层。原 PNG 不作像素修改。
